# Rails Chat

A simple real-time chat application built with Ruby on Rails.

## Features
- Single chatroom
- Real-time message updates
- Session-based username
- Minimal chat UI

## Live Demo
https://rails-chat-app-production.up.railway.app/

## Local Setup

```bash
bundle install
rails db:create
rails db:migrate
rails server
```

Then open:
[http://localhost:3000](http://localhost:3000)

## Tech Stack

* Ruby on Rails
* ActionCable
* PostgreSQL
* Tailwind CSS
